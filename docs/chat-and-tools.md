# Chat & Tools

[Getting Started](getting-started.md) · [Using Context](context.md)

Use Way Chat for supported short commands, or use a Tool's controls directly. Both can produce a result you inspect and use again.

**Remote AI is not enabled in this beta.** Way Chat will not answer arbitrary questions, summarize an entire website or invent a new workflow.

## Save a note with Context

Attach sample text or an example page reference, then send **記住** in Way Chat. This supported command saves the attached material as a note. Find it in My Way.

The command is intentionally shown as **記住** in this English guide because it is a verified beta example; UI language can be English or Traditional Chinese.

## Try a Tool

1. Open the full workspace. Extension users choose **Open Way Tools / 開啟 Way Tools** in Quick Way.
2. Choose **Text Toolkit / 文字工具箱** in the left **Capabilities / 能力** list. Mobile Web uses bottom **Tools / 工具**.
3. In **INPUT TEXT / 輸入文字**, type **way beta**.
4. Click **UPPERCASE / 轉成大寫**.
5. Inspect **WAY BETA** in **Last result / 最近結果** or **Tool Result / 工具結果** in Way Chat. On mobile, switch to Chat to see the conversation.

With text already in Text Toolkit, the supported Chat command **轉成大寫** also uses that tool input. From a Chat result, **View result / 查看結果** or **Adjust tool / 調整工具** can return you to the tool.

## Bring the result back to Chat

Choose **Send to Chat / 傳送到 Chat** beside a supported result. The output becomes attached material; choose your next command yourself. This does not run the next action automatically.

## Current Tools

| Tool | Typical use |
| --- | --- |
| Image Compressor / 圖片壓縮 | Compress a non-sensitive sample image |
| Text Toolkit / 文字工具箱 | Change case, clean spaces and count text |
| JSON Formatter / JSON 格式整理 | Format, minify or validate sample JSON |
| Quick Capture / 快速收集 | Save a short note |
| Link Toolkit / 連結工具箱 | Clean, extract, encode/decode and inspect links |
| Base64 Toolkit / Base64 工具箱 | Convert UTF-8 text and Base64 |
| Markdown Preview / Markdown 預覽 | Preview sample Markdown |
| Context Inspector / 脈絡檢視器 | Inspect current material and a redacted diagnostic summary |

Browser Capture is the Context entry: manual input on Web, explicit source-page collection in Extension.

Link checks do not scan a destination website for safety. Image files need to be selected again after a refresh. Use sample data and keep originals outside the beta workspace.

## My Way

Find saved notes, pinned/recent tools, Recipe results and Skills in My Way. Desktop has a right-hand area; mobile uses the bottom My Way tab. Web and Extension keep separate local data, with no account or cloud sync.
