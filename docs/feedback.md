# Feedback

[Known Issues](known-issues.md) · [Troubleshooting](troubleshooting.md) · [Safety](safety.md)

Report bugs, confusing wording or missing capabilities. English and Traditional Chinese are welcome; “unknown” is fine for versions you cannot find.

## Where to report

After this documentation repository is published and Issues are enabled, open its **Issues** tab and choose:

| Form | Use it for |
| --- | --- |
| Bug Report | An operation fails or behaves differently from what you expected |
| UX / Confusing Flow | A screen, label or next step is hard to understand |
| Feature Request | A real use case that current capabilities do not cover |

Before publication, invited testers should use their existing private contact with the owner. There is no separate public support service or beta access form promised here.

## Public means public

Remove passwords, API keys, credentials, private documents, sensitive Context, private URLs and identifying details before submission. Check screenshots for other tabs, names and content.

Do not attach the private beta package, a complete workspace, raw Context or unreviewed logs. If a report involves private information, use the existing private owner contact without sending secrets; do not put the sensitive details in a public Issue.

## Copy-paste report

~~~text
What I was trying to do / 我想做的事:
Web or Extension / 使用方式:
Device, OS, browser/version / 裝置、系統、瀏覽器:
Steps using non-sensitive examples / 操作步驟:
Expected / 預期:
Actual / 實際:
Could I recover? How? / 能否恢復、怎麼恢復:
Does it block further use? / 是否阻止繼續使用:
Screenshot, reviewed and redacted (optional) / 已檢查截圖（選填）:
Anything confusing / 哪裡不清楚:
~~~

One to three steps and a public example are enough. You do not need to understand the product's architecture or choose an internal priority.

## Optional diagnostic summary

Only provide one if useful or requested. In Quick Way, choose **Open Way Tools / 開啟 Way Tools**. In the full workspace, open **Context Inspector / 脈絡檢視器** from Capabilities (mobile Tools), then choose **Copy Share-safe / Redacted summary / 複製 Share-safe／遮罩摘要**.

Paste it into a draft and inspect it before sharing. Ordinary Copy is original content; the summary can still disclose domains, lengths and counts. A written description alone is acceptable.

If you cannot continue, describe the final step and whether [reloading](troubleshooting.md#restart-or-reload) helped. Clearing a workspace deletes data; keep non-sensitive feedback first.
