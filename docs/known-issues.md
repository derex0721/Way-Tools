# Known Issues

[Troubleshooting](troubleshooting.md) · [Feedback](feedback.md) · [Safety](safety.md)

This early beta has the following user-facing limitations. They remain open; documentation preparation has not fixed them.

## UX

| Limitation | Workaround |
| --- | --- |
| The expanded mobile **More / 更多** area has excessive vertical spacing | Scroll to the required control; tell us which item was hard to find. |
| Refreshing or reopening may unexpectedly return to Chat | Use bottom Tools/My Way on mobile or desktop Capabilities/My Way to return. |
| Context Inspector and the Share-safe summary are hard to discover | In the full workspace, search Capabilities for Context Inspector / 脈絡檢視器. Mobile begins with Tools. |
| Quick Way has no direct Context Inspector entry | Choose Open Way Tools / 開啟 Way Tools first, then open the inspector in the full extension. |

## Product and compatibility

- Way Chat supports current local commands; remote AI is not enabled.
- Only Clean & Save Links is built in as a Recipe. Skills start empty until saved from a successful supported Recipe.
- Web has no Quick Way and cannot collect from another tab.
- Web and Extension workspaces are separate. There are no accounts, cloud sync or cross-device sync.
- Sample image files need to be selected again after a refresh.
- Owner real-device acceptance includes Mac Chrome extension installation. It does not establish compatibility with every browser, OS, version or multi-window situation.
- Theme/Language are intended to remain after clearing the workspace. If they change, report the behavior; their retention is not a guaranteed device-wide result.

## Safe-use limits

Use only non-sensitive test data in a separate browser profile. The beta does not provide production-grade multi-user isolation. Share-safe summaries still need review, and workspace clearing is not a complete browser wipe.

See [Safety](safety.md) for the practical boundary.
