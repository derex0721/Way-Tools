# Safety & privacy

[Getting Started](getting-started.md) · [Feedback](feedback.md)

Friend Beta V0 is limited to approximately **3–10 trusted testers**. Use **non-sensitive test data** and a **separate browser profile**. A few sample notes, example.com URLs and images without private content are enough.

## Do not use these materials

- Passwords, authentication secrets or one-time codes.
- API keys or other credentials.
- Financial account credentials, payment information or card details.
- Confidential work data.
- Sensitive personal documents or private medical records.
- Any other secrets or material you would not want another user of your browser profile to see.

## Local data boundaries

There are no accounts or cloud sync. Web and Extension keep separate local workspaces. People sharing a browser profile may see the same data. This early beta does not provide production-grade multi-user security or isolation.

The public website is discoverable; its URL is not an invite-only access control. Private distribution of the extension does not change that Web boundary.

Choose what you attach deliberately and check the source before continuing. Browser page checks cannot recognize every sensitive situation. Do not treat the workspace as a backup.

## Before sharing

GitHub Issues are public. Remove names, private tabs, URLs, documents, sensitive Context and secrets from screenshots and descriptions. Do not attach the private beta package or a complete workspace.

Ordinary Copy copies original content. The **Share-safe / Redacted summary** reduces disclosure but can still include domains, lengths and counts. Inspect it before sending; see [Using Context](context.md#context-inspector-and-sharing). A plain description is sufficient.

## Clear test data

In Settings, choose **Clear Local Workspace / 清除本機工作區**, read the scope and confirm **Delete local workspace / 刪除本機工作區** only when ready.

This permanently deletes the current platform's notes, Chat, Context, results, Skills and run history. It cannot be undone. Web and Extension require separate clearing.

This is not a whole-browser wipe. Browser history, clipboard, downloads and some source-page information are outside this operation. [Troubleshooting](troubleshooting.md#clear-the-test-workspace) explains the confirmation and error message.

Do not publicly post a suspected issue that contains private data. Invited testers should contact the owner through their existing private channel without sending secrets.
